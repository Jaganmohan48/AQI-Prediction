# 🌫️ Air Quality Index (AQI) Prediction using Machine Learning

This project uses machine learning to predict the Air Quality Index (AQI) based on pollutant levels like PM2.5, PM10, NO₂, SO₂, and CO. It includes exploratory data analysis, model training, evaluation, and visual insights.

## 📌 Features
- Predict AQI based on air pollutants
- Exploratory Data Analysis with visualizations
- Feature importance chart
- Model performance evaluation (RMSE)
- Ready for deployment (Streamlit optional)

---

## 🧠 Machine Learning Model
- Algorithm used: `RandomForestRegressor`
- Target variable: `AQI`
- Features: PM2.5, PM10, NO₂, SO₂, CO

---

## 📊 Visualizations
- Heatmap of feature correlation
- Time-series pollutant trends
- Histogram of AQI distribution
- Actual vs Predicted scatter plot
- Feature importance bar chart
